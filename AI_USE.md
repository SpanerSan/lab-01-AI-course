# AI-use declaration

ChatGPT (OpenAI Codex) was used to explain the assignment, inspect the README
and related repository files, help prepare semantically parallel corpus
additions for the required Core tasks, execute and verify the provided scripts,
check the arithmetic, and format the submission report.

Parts 0 and 1 were executed with the repository's provided
`part0_tokenizers.py` and `part1_offline.py` scripts. The three required Core
extensions were added to `texts.py`, and their reported values were produced by
those same scripts. Part 3 was executed with the provided `part3_cost.py`
script.

The classroom/projector API key was not available, so Part 2 was not run.
Following the fallback stated in the README, the repository's official
`measurements.example.json` reference run from 2026-09-12 was used. All Claude
input/output token counts reported for Part 2 come from that file and are not
represented as a new API run.

ChatGPT was also used to verify that the reported calculations matched the
script outputs. No API execution or measurement result was fabricated.
